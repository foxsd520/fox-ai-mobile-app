# Fox AI Mobile App

This project is a real Expo-based mobile app for Fox. It includes a personal AI profile, business dashboard, and mobile-friendly interface for customers, projects, and tasks.

## Run locally

```bash
npm install
npm start
```

Then run:
- Android: `npm run android`
- iOS: `npm run ios`
- Web: `npm run web`

## Important

This repo now contains the real app starter code for the Fox mobile project. The app is built with Expo and can be extended into a full local/AI business dashboard.
